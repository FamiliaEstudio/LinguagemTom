# Artefatos históricos

Estes binários, VSIX e saídas LLVM/MLIR foram movidos das pastas de fonte para
preservar o material anterior à consolidação. Não foram recompilados, não comprovam
o comportamento dos fontes atuais e não devem ser usados nos testes do núcleo.

`generated/root`, `generated/exemplos` e `generated/runtime` indicam a pasta original;
`releases` contém os VSIX anteriores. Novos artefatos vão para `build/`, fora do Git.
